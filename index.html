Google Cloud 設定教學（點此展開）
  1. 把這個 HTML 上傳到你控制的 HTTPS 靜態網站（例如 GitHub Pages 或 Netlify），記下完整網址與 origin（只包含協定＋網域）。
  2. 開啟 Google Cloud Console，建立或選擇專案，啟用 Google Calendar API。
  3. 在 Google Auth Platform 設定品牌、使用者類型、資料存取權（Scopes）；個人測試建議選 External／Testing，新增自己的 Gmail 為測試使用者，並使用 https://www.googleapis.com/auth/calendar.readonly 唯讀權限。
  4. 在 Clients／憑證 新增 OAuth 用戶端，類型選 Web application。在 Authorized JavaScript origins 輸入網站 origin，例如 https://your-name.github.io；本機開發可用 http://localhost:8000。這個 token 模式不需要自行設定 redirect URI。
  5. 複製用戶端 ID（以 .apps.googleusercontent.com 結尾），填入上方，按「使用 Google 授權讀取」，選擇帳戶並核准唯讀權限。
  6. 連線成功後可選擇行事曆，網頁會讀取所選日附近 14 天的活動。可以勾選多個想看的行事曆，未勾選的行事曆不會讀取活動。

測試模式的 Google OAuth 授權可能有時間限制，並且僅允許測試使用者；如發布給其他人使用，可能需要 Google 審查。Google 專案設定介面名稱可能變動。
